# AICI — AI Command Inbox

> Turn Information Into Action

AICI is an AI-powered inbox assistant that transforms emails, calendar events, and notifications into actionable commands.

Built for the Corsair Hackathon.

## Vision

AICI converts information into actions.

Examples:

**Email**

> "Your credit card bill is due tomorrow"

↓

**Command**

> Pay Credit Card Bill  
> Priority: High
